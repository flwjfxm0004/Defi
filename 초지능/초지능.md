# [목표]

`SSOT-HW` 단일 로컬 워크스테이션에서 외부 의존 없이 동작하며, **인간이 한 번 실행하면 이후 개입 없이** 자기 다음 세대의 **고차 추상화 연산자(커리큘럼 궤적 내 필수 발명·승격) 및 이에 연동된 생성기 그래프 구조·탐색 사전분포·조기 기각 검증 전략**을 생성·채점·채택하는 폐쇄 RSI(Recursive Self-Improvement) 루프를 통해 **초지능을 달성하는 아키텍처**를 설계·구현한다.
- **불변 오라클 규약 (`SSOT-Soundness`):** 보상 해킹·Wireheading 원천 차단을 위해 **최종 정합성 오라클 커널(Soundness Verifier)은 절대 불변으로 고정**한다. 반례 조기 기각 순서·경계 가지치기(Pruning Schedule) 전략만 자기개선 대상으로 허용하되, ① `(task_id, stage_spec)` 명세 쌍별로 귀속된 기검증 정답 해법 아카이브 전수에 대한 **오기각률 `0%`(Zero False-Pruning, 빈 아카이브 시 `0/0 := 0%`) 완전성 불변식**과 ② **단일 `step_generation`(`ops_budget >= 1`) 진입 시 `SSOT-HV` ①의 비공집합 단계 보유 활성 과업 집합 $T_{\text{in}}$($T_{\text{in}} = \emptyset$ 무과업·빈히스토리 호출은 `nvfp4_quantize` 최소 1회 외 `0 op`으로 상태·카운터·단계를 동결 반환)에 대해 `unpruned_reserve = ceil(0.25 * ops_budget)`($\ge 25\%$)을 선예약하여 초기 탐색 구간(Phase ②) 중 `unpruned_ops == 0`을 고정한 채 가지치기 탐색·고정 프로브(`SSOT-Dedup`/`c_size`)·직전 해법 회귀 검증 합산 연산량을 `ops_used <= pruned_cap = ops_budget - unpruned_reserve`(`= floor(0.75 * ops_budget)`) 이하로 하드캡(`unpruned_reserve` 선잠식 원천 차단)한 뒤, 초기 탐색 종료 시점에 $S_t$ 전 쌍 완주 후보 집합 $\mathcal{C}_{g,t}^{\text{full}}$(직전 바인딩 캐시·재평가 포함) 기준 공급 단계 히스토리 $S_t$($|S_t| \ge 1$) 전 단계 만점 미달(미포화) 과업 집합 $T_{\text{imp}} = \{t \in T_{\text{in}} : \max_{h \in \mathcal{C}_{g,t}^{\text{full}}} f_1(h, t) < |S_t|/L_{\max}\} \ne \emptyset$(동치 조건 $\max_h \min_{s \in S_t} \text{acc}_{t,s}(h) < 1.0$, $\mathcal{C}_{g,t}^{\text{full}} = \emptyset$ 시 $\max_h := 0.0$)이면 예약 슬라이스(Phase ③)를 $T_{\text{imp}}$ 대상 비가지치기·완화 탐색 전용으로 의무 집행(구문 해시 중복만 `0 op` 선제거 후 후보의 $T_{\text{imp}}$ 비가지치기 본평가를 먼저 수행하고 직결 1회 고정 프로브로 `c_size`·`SSOT-Dedup`을 사후 적용해 두 연산을 함께 `unpruned_ops`로 기록하되 $T_{\text{imp}}$ 본평가 없는 선행·단독 프로브 호출은 금지하며, 완주+프로브 선예약 단위로 잔여 예산이 부족한 꼬리 구간 또는 구문 해시 비중복 후보 고갈 시에는 `unpruned_ops >= unpruned_reserve` 도달까지 단일 격자·단일 `b0` `1 op` 비가지치기 폴백 평가를 반복 수행[$\mathcal{P}_{g,t}$·$c^*_t$ 미편입]해 종료 시점 미포화 지속 시 `unpruned_ops >= unpruned_reserve`, `ops_used - unpruned_ops <= pruned_cap`, `ops_used <= ops_budget` 동시 보장)하고, $T_{\text{imp}} = \emptyset$(현 단계 만점 및 이전 단계 비퇴행 동시 달성; 비가지치기 탐색 도중 조기 달성 포함)이면 캡을 해제해 잔여 예산을 동치류 저복잡도 정밀화 탐색으로 전환**하는 안전장치를 함께 강제한다.

과업 정합 달성도(누적 사다리 점수 $\in [0, 1]$)를 제1축으로 두고, 다음 4대 비용·수렴 목표를 **다목적 Pareto 최적 전선**(후보 수준 과업별 비지배 전선 아카이브 $\mathcal{P}_{g,t}$ [`SSOT-HV` 참조] 및 세대 궤적 수준 분리 정의) 위에서 달성하라:
- 최소 연산 (결정론적 **입력 격자당 평균** 원시 연산 스텝 `ops_count` 및 이론 `FLOPs`)
- 최소 물리 비용 (`SSOT-Roofline`, §1·§4 아키텍처 설계 축: 단일 로컬 노드 실측 wall-clock을 배제하고 `SSOT-HW`·`SSOT-Mem` 대역폭·전력 상한 위에서 다계층 스테이지 $s$별 지연 하한 $T_{\text{lat},s}$ 및 피크 처리율 $\Pi_{\text{peak},s}$를 포함한 단독 스테이지 Roofline 하한 $\hat{t}_s = T_{\text{lat},s} + \max\!\left(F_s/\Pi_{\text{peak},s},\; \max_l B_{s,l}/\text{BW}_{\text{eff},l}\right)$[미사용 연산·링크 항 `0/0 := 0`; 반이중 채널은 읽기+쓰기 합산 $(B_R+B_W)/\text{BW}_{\text{eff},l}$, 전이중 PCIe·비대칭 NVMe는 읽기/쓰기 채널 분리 산정; 순차 실행은 $T_{\text{seq}} = \sum_s \hat{t}_s$; 동시 활성 스테이지 집합 $\mathcal{S}_{\text{conc}}$의 $N_{\text{micro}} \ge 1$ 마이크로배치 파이프라인은 연산기 $u$ 공유 스테이지 집합 $\mathcal{E}_u$ 기준 분할 보존식 $\sum_{s \in \mathcal{S}_{\text{conc}}} \text{BW}_{s,l} \le \text{BW}_{\text{eff},l},\; \sum_{s \in \mathcal{S}_{\text{conc}} \cap \mathcal{E}_u} \Pi_{s,\text{alloc}} \le \Pi_{\text{peak},u},\; P_{\text{compute,idle}} + \sum_{s \in \mathcal{S}_{\text{conc}}} P_{\text{dyn,compute},s} \le P_{\text{compute,peak}}$($P_{\text{dyn,compute},s} \ge 0$, NVMe·플랫폼 동적전력은 $P_{\text{plat}}(t)$에 분리 귀속; $F_{s,\text{micro}}>0 \implies \Pi_{s,\text{alloc}}>0,\; B_{s,\text{micro},l}>0 \implies \text{BW}_{s,l}>0$, 미사용 항 `0/0 := 0`) 하의 할당 시간 $\hat{t}_{s,\text{micro}}^{\text{alloc}} = T_{\text{lat},s} + \max\!\left(F_{s,\text{micro}}/\Pi_{s,\text{alloc}},\; \max_l B_{s,\text{micro},l}/\text{BW}_{s,l}\right)$ 기준 $T_{\text{pipe}} = \sum_s \hat{t}_{s,\text{micro}}^{\text{alloc}} + (N_{\text{micro}} - 1)\max_s \hat{t}_{s,\text{micro}}^{\text{alloc}}$ 적용] 및 세대당 소비 에너지 `J`[$E_{\text{sys}} = \int_0^{T_{\text{gen}}} P_{\text{sys}}(t)\,dt$, 연산 서브시스템 $E_{\text{compute}} = \int_0^{T_{\text{gen}}} P_{\text{compute}}(t)\,dt$ 구분, `1 Wh = 3,600 J` 병기 가능]·메모리 시공간 점유량 `GB·s`; §5 후보 전선은 플랫폼 무관 `SSOT-HV` 3축 사용)
- 최소 활성 상태(모델) 크기 (§1·§4 정적 타입 바이트 크기 및 §5 고정 프로브 격자 기준 정규화 추상 상태 + 연산 그래프 복잡도 [`SSOT-HV` 참조])
- 최고 수렴 속도 (메타 루프 궤적 지표: 목표 난이도 도달 세대 수 및 누적 연산 예산 최소화)

현 시점의 사전 학술 지식을 참고해도 좋으나 외부 웹·브라우저 조회(마스터·서브에이전트 전원의 `search_web` 및 `browser` 서브에이전트 등 일체 호출 금지)나 기존 틀에 얽매이지 말고, **제1원리(물리적 정보량·계산복잡도·하드웨어 대역폭 한계)에서 출발해 아키텍처를 발명하라.**

**장식 인용 금지:** `SSOT-HW` 수치를 서술용 장식으로 복붙하면 무효다. §1·§2·§4·§5 전반에서 다음 두 경계를 정량 수식과 코드로 일관되게 구속하라:
1. **이원 메모리 및 PCIe 5.0·스토리지·전력 보존 경계 (`SSOT-Mem`, §1·§4·§5):** 커널·CUDA 컨텍스트·2D 터미널 프레임버퍼·`KVM` 런타임 예약 메모리를 선공제하고 `4,096 B` 페이지 정렬한 계층별 가용 풀($0 < M_{\text{VRAM,avail}} < 384\text{ GB}$[장당 균등 분할 시 $< 96\text{ GB}$], $0 < M_{\text{DRAM,avail}} < 1{,}000\text{ GB},\; M_{\text{avail}} = M_{\text{VRAM,avail}} + M_{\text{DRAM,avail}} < 1{,}384\text{ GB},\; 0 \le M_{\text{NVMe,avail}} \le 10.0\text{ TB}$) 내에서 `SSOT-HW` 상한에 따른 반이중 GDDR7($\text{BW}_{\text{VRAM,R}} + \text{BW}_{\text{VRAM,W}} \le \text{BW}_{\text{VRAM,peak}}$, 단일 카드 로컬 커널 분리 적용)·반이중 DDR5($\text{BW}_{\text{DRAM,R}} + \text{BW}_{\text{DRAM,W}} \le \text{BW}_{\text{DRAM,peak}}$)·전이중 PCIe 5.0(호스트 메모리 스트리밍 동반 시 DDR5 반이중 상한 동시 적용, P2P는 루트 컴플렉스 경유)·비대칭 4-way NVMe 읽기/쓰기 병목 및 전력 보존식($P_{\text{compute}}(t) \in [160, 1{,}550]\text{W},\; P_{\text{plat}}(t) \in [90, 350]\text{W},\; P_{\text{sys}}(t) = P_{\text{compute}}(t) + P_{\text{plat}}(t) \in [250, 1{,}900]\text{W}$)을 반영한 바이트 단위 상태 배치와 세대당 연산·전송·에너지 예산(`FLOPs·Bytes·J`)을 제시하고, §5의 결정론적 추상 상태 크기 카운터와 연결하라.
2. **NVFP4 양자화 잡음 상쇄 및 소프트웨어 동형 구현 경계 (`SSOT-NVFP4`, §2·§5):**
   - **이론 수식 경계 (§2):** `SSOT-HW` 밀집(`7.022 PFLOPS`) vs 2:4 희소(`14.044 PFLOPS` — 연산자 자체가 대수적 2:4 구조 희소가 아니면 감쇠 스케일이 반영된 2:4 절단 오차 $\|\varepsilon_{2:4}\|_\infty$를 총 오차 $\bar{\varepsilon}$에 필수 합산) 조건과 **단일 무한노름 $\|\cdot\|_\infty$ 기준 전방 불변 유계 큐브 $\mathcal{K} = \{x \in \mathbb{R}^N : \|x\|_\infty \le R_{\max}\}$**($\tilde{x}_0, x^* \in \mathcal{K}$)를 명시하고, 순수 검증기 단독 기각 시 궤적 길이 $T$에 대해 생존 확률이 $p^T \to 0$으로 붕괴하는 한계를 넘어 **연속 완화 공간의 감쇠 잔차(Residual) 양자화 $\gamma$-수축 동역학($\tilde{x}_{t+1} = \tilde{x}_t + \operatorname{Q}_{\text{NVFP4}}(\alpha(\Phi(\tilde{x}_t) - \tilde{x}_t))$ 또는 비팽창 투영 결합 $\Pi_{\mathcal{K}}(\cdots)$ 등 $\gamma \in [0, 1)$, 완화 편향 $\delta_{\text{relax}} = \|x^* - m^*\|_\infty$)이 도메인 전방 불변식 $\|x^*\|_\infty + \gamma(R_{\max} + \|x^*\|_\infty) + \bar{\varepsilon} \le R_{\max}$(또는 $x^* \in \mathcal{K}$ 위 비팽창 박스 클램핑 $\Pi_{\mathcal{K}}$ 결합 / 중심 볼 $\|\tilde{x}_0 - x^*\|_\infty \le r \le R_{\max} - \|x^*\|_\infty$ 불변식 $\frac{\bar{\varepsilon}}{1-\gamma} \le r$) 및 유한 스텝 $T$ 포획 부등식 $\delta_{\text{relax}} + \gamma^T \|\tilde{x}_0 - x^*\|_\infty + \frac{1-\gamma^T}{1-\gamma}\bar{\varepsilon} < \frac{\Delta_{\min}}{2}$($\bar{\varepsilon} = \sup_{x \in \mathcal{K}}\|\varepsilon_{\text{total}}(x)\|_\infty$)를 동시에 만족함 + 비공집합 0차원 이산 대수 점격자 $\mathcal{M}$($|\mathcal{M}| \ge 1$; $|\mathcal{M}| \ge 2$일 때 최소 분리 거리 $\Delta_{\min} = \min_{m \ne m' \in \mathcal{M}}\|m - m'\|_\infty > 0$, $|\mathcal{M}| = 1$일 때 $\Delta_{\min} := +\infty$; Voronoi 열린구 반경 $\Delta_{\min}/2$, 경계 동률 시 사전순 시그니처 결정론 타이브레이크) 위 국소 상수 최근접 사영($\Pi_{\mathcal{M}}(m^* + e) = m^*$) + 결정론적 무결성 검증기(`9995WX` Zen 5 `AVX-512` / 형식 커널)** 결합이 양자화·근사 오차를 누적 발산 없이 흡수·교정하는 수학적 상한을 제시하라.
   - **소프트웨어 동형 실행 규격 (§5):** `main.py` 최상위 공개 함수 `nvfp4_quantize`(`Sequence[float]` 입력 $\to$ `list[float]` 반환)로 다음 결정론적 파이프라인을 구현하고 `step_generation` 내부 연속 완화/점수화 텐서에 매 세대 실호출하여 §5(a) 인용 표와 1:1 직결하라(빈 시퀀스는 `[]` 반환; 거대 `int` 입력의 `float(v)`·`math.isnan(v)` `OverflowError` 및 `min`/`max` `NaN` 왜곡을 원천 차단하도록 각 원소는 `v != v`[`NaN`] 시 즉시 `0.0`으로 치환하고, 그 외에는 `float` 변환 전 `±3.4028234663852886e38`[`FLT_MAX`, `±Inf` 포함] 범위로 먼저 비교·클램핑한 뒤 `float(v) + 0.0`으로 정규화하되, **입력 원소 자체에 대한 별도 `FP32` 선반올림 없이 클램핑된 Python `FP64` 값을 이후 `a_max`·`b_max`·`b_j` 연산에 그대로 사용**):
     - **① 전역 `FP32` 텐서 스케일:** $a_{\max} = \max_i |x_i|$에 대해 $a_{\max} == 0.0$이면 나눗셈 없이 `[0.0]*N`을 즉시 반환하고, $a_{\max} > 0$이면 `sg = struct.unpack('<f', struct.pack('<f', a_max / (448.0 * 6.0)))[0]`을 계산하되, `FP32` 최소 비정규수 반값 미달 언더플로 구간($0 < a_{\max} \le 2688 \cdot 2^{-150} \approx 1.883345\times 10^{-42}$)의 조기 영점 소실을 막기 위해 `s_global = sg if sg > 0.0 else 2.0**-149`(`FP32` 최소 양수 비정규수 하한)로 확정한다.
     - **② 16-원소 `PTX .ue4m3`(`S=0 OCP E4M3FN`) 마이크로블록 스케일:** 길이가 16의 배수가 아닐 때 꼬리 블록을 `0.0`으로 패딩(복원 후 원래 길이 `N` 슬라이싱)하고, 16-원소 패딩 블록의 절댓값 최댓값 $b_{\max} = \max_{0 \le j < 16} |b_j|$에 대해 $s_{\text{raw}} = b_{\max} / (6.0 \cdot s_{\text{global}})$(연속 나눗셈 `b_max / 6.0 / s_global` 이중 반올림 금지)을 127개 유한 격자(`0x00..0x7E`, `bias=7`, `Inf` 없음, `0x7F=NaN` 진입 금지·최댓값 `448.0` 포화 클램핑[`s_global` 하향 반올림 시 $s_{\text{raw}} > 448.0$ 방어], 코드 $c \in \{0,\dots,126\}$[$e = c \gg 3,\; m = c \mathbin{\&} 7$]별 격자값 $e=0$ 시 $m\cdot 2^{-9}$[최소 양수 비정규수 $2^{-9}$]·$1 \le e \le 15$ 시 $(1 + m/8)\cdot 2^{e-7}$, 7-bit 코드 최하위 비트 `0` 짝수 방향 RNE)로 양자화해 `s_block`을 얻는다. **단, 영벡터 블록뿐 아니라 $0 < s_{\text{raw}} \le 2^{-10}$ 비-영벡터 블록이 `s_block == 0.0`(`0x00`)으로 언더플로된 경우에도 `0/0` 나눗셈 없이 해당 블록 양자화값을 전부 `0.0`으로 반환**한다.
     - **③ `E2M1` 비균일 RNE 투영 및 부호 정규화 역양자화:** `s_block > 0.0` 블록의 각 원소 $b_j / (s_{\text{global}} \cdot s_{\text{block}})$(`b_j / s_global / s_block` 순차 나눗셈에 따른 2회 반올림 배제)을 `±6.0` 포화 클램핑 후 `E2M1` 비균일 대표값 격자(`{0.0, ±0.5, ±1.0, ±1.5, ±2.0, ±3.0, ±4.0, ±6.0}`, 중점 동률 `{±0.25, ±0.75, ±1.25, ±1.75, ±2.5, ±3.5, ±5.0}` 시 가수 최하위 비트 `M=0` 짝수 격자 `{0.0, ±1.0, ±2.0, ±4.0}` 방향 RNE; 균일 `INT4` 위장 시 무효)로 투영해 `-0.0` 직렬화 드리프트가 없도록 `(q_j * s_block * s_global) + 0.0`을 반환한다.

**Tier B 명세 의무 (`SSOT-TierB`):** Tier B는 §5 코드에서 실행되지 않는 대신, §4에서 위 **15개 정본 키 전부**의 무가중치(`0 B`) 결정론적 입출력 변환기(어휘·AST·PTY·픽셀 Transducer — 신경망·의미 추론기 은닉 밀수 금지) 경계·채점 주기·호스트 `x86_64` `4KiB` 네이티브 실행 vs 격리 컨테이너(`oci_x86_64`) vs `KVM x86_64` 하드웨어 가상화 오버헤드를 반영한 `SSOT-HW`/`SSOT-Mem` 연산·메모리·NVMe·전력 보존 예산·정규화·Pareto 기여식을 빠짐없이 명세하라(누락 시 무효).

**비지배 파레토 전선 HV 및 반증 정본 (`SSOT-HV`):**
- **3차원 결정론적 목적벡터 $(f_1, u_{\text{ops}}, u_{\text{size}}) \in [0, 1] \times (0, 1]^2$:**
  - ① **단일 단계 공급 규약 및 보편 분모($L_{\max}=4$) 누적 사다리 점수:** 호출자(`__main__` 및 외부 심판기)는 매 `step_generation` 호출 시 각 `task_id`에 대해 **현재 활성 단계 1개 분량의 비공집합 입출력 쌍 리스트($|s| \ge 1$)**를 전달하며, 엔진은 `task_id`별 순서 보존 단계 히스토리 $S_t$에 `tuple(pairs)` 내용 동등 비교 기준 미등장 비공집합 단계만 최대 $L_{\max}=4$개까지 추가(`len(pairs) >= 1 and len(S_t) < 4`일 때만 추가하여 동일 단계 재시도 세대 중복 추가 방지; 비정상 빈 쌍 단독 유입으로 $|S_t| == 0$인 키가 `0.0 == 0/4` 허위 포화로 오분류되지 않도록 현 세대 유효 활성 과업 집합을 $T_{\text{in}} := \{t \in \text{keys}(\text{train\_tasks}) : |S_t| \ge 1\}$로 확정해 모든 $t \in T_{\text{in}}$에서 $1 \le |S_t| \le 4$를 보장하며, $S_t = \emptyset \implies f_1 := 0.0$)한다. 단계별 정확도는 IEEE-754 역수 누적 반올림 오차(`(1.0/|s|)*|s| < 1.0`)로 인한 `== |S_t|/L_{\max}` 만점 비교 실패를 원천 차단하도록 정수 정답 쌍 합산 후 단일 나눗셈 $\text{acc}_{t,s}(c) = \left(\sum_{(X,Y)\in s}\mathbb{I}[c(X)==Y]\right) / |s| \in [0, 1]$($|s|==0$ 시 `0.0`, 전수 일치 시 비트 정확 `1.0`)로 산정하며, `'T1'~'T3'` 하드코딩 없이 등록·미등록(`T4_hidden` 등)·대조군 전 과업에 동일한 $L_{\max}=4$를 적용하여 $f_1(c, t) = \left(\sum_{s \in S_t} \text{acc}_{t,s}(c)\right) / L_{\max} \in [0, 1]$로 정의한다(단일 단계 과업 만점 시 $f_1 = 0.25$, 4단계 누적 만점 시 $f_1 = 1.00$ 비트 정확 일치).
  - ② **격자당 평균 연산 비용:** 난이도 해금 시 평가 격자 수 확대 인플레이션과 조기 기각 후보의 미평가 쌍 생략에 따른 비용 과소 계상($u_{\text{ops}}$ 허위 부풀리기)을 동시에 차단하도록, $S_t$ 전 쌍($N_{\text{grids}}(S_t) = \sum_{s \in S_t} |s|$개 입력 격자, $0$ 시 `0.0`) 평가를 완주한 후보에 한해 $c_{\text{ops}}(c, t) = \frac{1}{N_{\text{grids}}(S_t)}\sum_{s \in S_t}\sum_{(X,Y)\in s}\text{ops}(c, X)$로 정의한다(조기 기각으로 일부 쌍만 실행 후 중단된 후보는 완주 전까지 $\mathcal{P}_{g,t}$ 편입 및 $c^*_t$ 바인딩 금지).
  - ③ **고정 프로브 정규화 상태·그래프 복잡도:** 단계별 격자 면적 확대에 따른 복잡도 착시 감소를 차단하도록 **전 세대 불변 고정 프로브 격자 집합 $\mathcal{X}_{\text{probe}}$($|\mathcal{X}_{\text{probe}}| \ge 2$, §5(a) `SSOT-Dedup` 공용) 전용 측정** $c_{\text{size}} = \frac{1}{|\mathcal{X}_{\text{probe}}|}\sum_{X \in \mathcal{X}_{\text{probe}}}\frac{S_{\text{cells}}(c, X)}{|X|} + \lambda(|V|+|E|)$로 단일화한다(단, $|X| = H_X W_X \ge 1$, $S_{\text{cells}}(c, X) := \sum_{v \in V_{\text{eval}}(c)} |G_v(X)|$는 프로브 $X$ 입력 시 승격 매크로 내부 실행 리프 `b0_*`를 포함한 모든 실행 원시 연산 노드의 출력 격자 셀 수 총합으로 매크로 은닉을 차단하며, $\lambda(|V|+|E|)$는 승격 매크로 호출을 단일 연산자 노드로 계상한 압축 후보 DAG/AST 크기로 추상화 승격의 MDL 압축 이득을 반영). 두 비용 축은 $u_k(c_k) = \frac{1}{1 + \alpha_k c_k} \in (0, 1]$ ($k \in \{\text{ops}, \text{size}\}$, $\alpha_{\text{ops}}, \alpha_{\text{size}}, \lambda, \epsilon > 0$은 Phase 0 공개 계약 고정)로 변환한다.
- **과업별 비지배 아카이브 르베그 초체적 및 무조건적 단조성:** 고정 참조점 $r_0 = (0, 0, 0)$ 위에서 $\mathcal{C}_{g,t}^{\text{full}}$ 내 정확도 양수($f_1 > 0$) 완주 후보만 편입한 비지배 전선 합집합 $\mathcal{P}_{g,t} = \text{Nondom}(\mathcal{P}_{g-1,t} \cup \{v(c, t)\}_{c\in\mathcal{C}_{g,t}^{\text{full}},\, f_1(c,t)>0})$(기편입 3차원 목적벡터 하한 증인 불변 보존 및 성분별 약우월 $v_{\text{new}} \ge v_{\text{old}}$ 시에만 교체하여 $\Delta\text{HV}_g \ge 0$ 무조건 보장; 동일 3차원 좌표 중복 제거; $\mathcal{P}=\emptyset$ 시 $\text{HV}:=0.0$)의 지배 초직육면체 합집합 **3차원 르베그 측도**로 HV를 산출한다(후보가 확장된 $S_t$에서 재평가되어 더 높은 $f_1$을 달성하면 신규 점으로 합집합 편입). 세대 증분은 현 호출 `train_tasks` 키 집합 $T_{\text{in}}$ 동등 비교($T_{\text{in}}=\emptyset$ 시 $0.0$, 그 외 $\Delta\text{HV}_g = \frac{1}{|T_{\text{in}}|}\sum_{t \in T_{\text{in}}}[\text{HV}(\mathcal{P}_{g,t}) - \text{HV}(\mathcal{P}_{g-1,t})] \ge 0$; 단일 후보 스칼라 곱·전역 캐시 이종 차감·참조점 변경·가중치 조작·`max(0.0, ...)` 음수 클램핑 은폐 시 무효; IEEE-754 부동소수점 슬래브 분할 `-1 ULP` 반올림 오차에 의한 음수 차분 발생을 원천 배제하도록 **`fractions.Fraction(x)` 정확 이진 유리수 기반 $z$-축 정렬 2D 스카이라인 스윕 $O(|\mathcal{P}|\log|\mathcal{P}| \sim |\mathcal{P}|^2)$ 후 `float(hv_exact - hv_prev_exact)` 변환 필수**)로 정의한다.
- **정체 반증 vs 활성 히스토리 포화 수렴 분기:** 과업별 직전 최우수 정확도 $f_{1,\text{prev}}(t)$(미등장 신규 `task_id`는 `0.0`) 대비 동일 활성 집합 $T_{\text{in}}$ 평균 증분 $\Delta\overline{f}_{1,g} = |T_{\text{in}}|^{-1}\sum_{t \in T_{\text{in}}}(f_1(c^*_{g,t}, t) - f_{1,\text{prev}}(t))$($c^*_{g,t} \equiv c^*_t$는 현 세대 종료 시점 바인딩 최우수 Object 해법; $T_{\text{in}}=\emptyset$ 시 `0.0`, $T_{\text{in}} \ne \emptyset$ 시 세대 판정 직후 $t \in T_{\text{in}}$에 한해 $f_{1,\text{prev}}(t) \leftarrow f_1(c^*_{g,t}, t)$ 갱신)에 기반해 세대 유의미 진전을 $\text{progress}_g \iff (\Delta\text{HV}_g \ge \epsilon) \lor (\Delta\text{HV}_g > 0 \land \Delta\overline{f}_{1,g} > 0)$으로 정의한다($T_{\text{in}}=\emptyset$ 무과업 호출은 상태·카운터·단계를 동결 유지). **현 공급 히스토리 $S_t$ 전 단계 만점 미달 과업이 존재하는 미포화 상태**($T_{\text{in}} \ne \emptyset \land \exists t \in T_{\text{in}},\; f_1(c^*_t, t) < |S_t|/L_{\max}$)에서 내부 재실행 소진 후 $N_1$세대 연속 $\neg\text{progress}_g$(정확도 순증 없는 미세 잡음 $0 \le \Delta\text{HV}_g < \epsilon$ 발생 시 정체 카운터 리셋 금지) 발생 시 **Object-level 아카이브 $\mathcal{P}_{g,t}$는 보존한 채 Meta-level 상태만 직전 체크포인트(`ckpt_stack`)로 롤백 및 금기 아카이브(Tabu Blacklist) 이월**을 수행하되, **현 활성 전 과업이 공급된 $S_t$ 전 단계 만점에 도달한 포화 상태**($T_{\text{in}} \ne \emptyset \land \forall t \in T_{\text{in}},\; f_1(c^*_t, t) == |S_t|/L_{\max}$ — 4단계 최종 `d_max=3` 만점 $f_1=1.0$ 및 단일 단계 전이 과업 `T4_hidden` 만점 $|S_t|=1, f_1=0.25$ 재공급 세대 모두 포함)에서는 정체 카운트·재실행·정체 롤백을 면제하고 **포화 수렴 / ($\min_{t \in T_{\text{in}}}|S_t| > \text{current\_stage}$ 만족 시) 차상위 단계 해금(및 잔여 예산 저복잡도 정밀화)**으로 분기한다.

# [진정한 폐루프 RSI 조건 — 단순 탐색·밴딧 위장 금지]

실행 이후 AI가 자기 다음 세대를 만들고, 벤치가 자동 채점하여 통과 시 채택하며, 포화 신호 도달 시 난이도가 자동 상승한다.
- **가짜 RSI 무효 1 (고정 생성기 탐색):** 생성기는 고정된 채 태스크 해법(Object-level 후보 프로그램)만 유전 알고리즘·MCTS·열거 탐색으로 찾는 것은 단순 탐색이지 RSI가 아니므로 **즉시 무효다.**
- **가짜 RSI 무효 2 (단순 가중치 밴딧):** 고정된 기본 연산자 목록 위에서 확률 가중치(Multi-Armed Bandit)만 미세 조정하는 것은 구조적 자기개선이 아니므로 **즉시 무효다.**
- **Object-level vs Meta-level 구조적 공진화:** 커리큘럼 루프 중 **새로운 고차 추상화 연산자(합성 매크로·에너지 커널·서브루틴)의 발명·승격이 최소 1회 이상(고차 합성 단계 해금 시 필수) 반드시 성립**해야 하며, 세대 전환($g \to g+1$) 메타 채택은 신규 고차 연산자 승격과 연동된(또는 기승격 고차 기저 위에서의) **생성기 그래프·사전분포·조기 기각 스케줄의 공진화 재작성**을 수행해 다음 세대의 유효 탐색 반경·합성 깊이를 단축해야 한다.
- **다양성 보존:** 채택된 메타 상태가 다음 세대에 반영되는 메커니즘과 함께, **채택되지 않은 후보의 처리 및 다양성 유지(엔트로피 하한·니치 아카이브·행동 시그니처 거리 보존·기각 시그니처 금기 이월) 방식**을 반드시 답하라.

# [LLM 패러다임 금지]

**`SSOT-TierB` 15개 정본 키 전부의 명세 의무 전항(§5(e) `TierBAdapter`의 `budget()` 6키 고유성·페이지 정렬·전력/광속 하한 및 `protocol()` 5키 계약과 1:1 일치하는 예산·주기·변환 경계·정규화·Pareto 기여식)을 마크다운 표로 제시하라.** 그리고 유한 상태기계(FSM) 우선순위가 완결된(단일 세대 선후 순서: ① `SSOT-Soundness` Phase ② 가지치기 탐색 후 미포화[$T_{\text{imp}} \ne \emptyset$] 시 Phase ③ `unpruned_reserve` 집행[포화 시 저복잡도 정밀화 전환] $\to$ ② `SSOT-HV` 세대 유의미 진전[$\text{progress}_g$] 달성 여부에 따른 메타 채택 후보 확정[정체 카운터 `0` 리셋 및 `ckpt_stack.append`] vs 미진전[$\neg\text{progress}_g$] 분기[포화 시 정체 카운트·롤백 면제 / 미포화 시 정체 카운터 증가 및 $N_1$ 연속 정체 롤백], 그리고 메타 채택·반증과 독립적인 `current_stage` 상승 판정 $\to$ ③ 말미 `self.meta_update` 단일 분기 이월/초기화) 4대 전이 조건을 수식·임계값으로 명시하라:
- **채택 조건:** Object-level 해법·$\mathcal{P}_{g,t}$ 갱신(`meta_update` 무관)과 Meta-level 전이를 분리하되, `meta_update=True`에서 고차 추상화 연산자 발명·승격 및 생성기 그래프·사전분포·가지치기 공진화 후보가 `SSOT-Soundness`·이전 단계 비퇴행·`SSOT-HV` $\text{progress}_g$ 기준(미세 잡음 시 카운터 리셋·적재 배제 포함)을 만족할 때 직전 메타 상태를 `ckpt_stack`에 보존하고 $\mathcal{M}_{g+1}$로 채택되는 조건.
- **반증 조건:** `SSOT-HV` 미포화 정체 조건(내부 재실행 소진 후 연속 $N_1$회 미진전) 성립 시 `ckpt_stack.pop()`(빈 스택 시 초기 $\mathcal{M}_0$ + 사전분포 다양화 리셋)으로 직전 메타 상태를 실질 복원(No-op 롤백 금지, 복원 직후 정체 카운터 `0` 초기화, 기각 시그니처 영구 Tabu 등록, $\mathcal{P}_{g,t}$ 비롤백 보존)하며 이를 활성 히스토리 만점 포화 수렴 면제 분기와 구분하는 기준.
- **난이도 상승 조건:** `meta_update` 무관 동일 기준으로 `SSOT-HV` 차상위 단계 해금 조건을 만족했을 때 `current_stage`가 상한 $d_{\max}$ 이내로 증가하는 메커니즘, 및 `SSOT-HV`의 중복 제거 히스토리 $S_t$·전 쌍 완주·보편 분모($L_{\max}=4$)·약우월 교체 정의 위에서 단계 해금 직후에도 $\Delta\text{HV}_g \ge 0$ 단조 비감소가 성립하는 수리적 근거.
- **재실행 조건:** 초기 탐색 종료 시 $T_{\text{imp}} \ne \emptyset$ 발생에 따라 반증 카운터 증가 전 최대 몇 회($K_{\text{retry}}$)까지 단일 `step_generation`의 `SSOT-Soundness`·`SSOT-Budget` 예산 내에서 스칼라 탐색 온도 $\tau > 0$·서브예산 비율·추상화 범위 및 Phase ③ 예약 탐색 슬라이스를 자동 조정해 재실행하는지.

## 5. RSI 루프 코드 및 검증 증적

**외부 서드파티 패키지(`numpy` 등) 의존이나 미검증 조건부 분기 없이 파이썬 표준 라이브러리 단독 구현만으로 `ImportError` 없이 100% 비트·수치 결정론적 결과로 즉시 완주**하는 **`main.py` 전문(코드·주석 내 `# ...` 중략·생략 표기 시 즉시 무효)**과 Phase 0~4 검증 로그(순수 7-bit ASCII 표준 출력·JSONL, Phase 3 코드 분량 및 `SSOT-Budget` 단독 실행 시간 규격 준수, 압축 표 출력 권장)를 제시하라.

### (a) 핵심 메커니즘 및 4대 조건 인용 표

§2의 **모든 핵심 메커니즘(`M1`, `M2`, ... 각각 반드시 별도 행으로 분리 — 통합 기재 시 무효)**과 §4의 **4대 조건(채택·반증·난이도 상승·재실행 각각 별도 행 필수)**을 **sub-claim으로 분해**해 아래 표를 **빠짐없이 채워라**.

| 메커니즘/조건 | sub-claim | 정의 심볼·줄 | 평가·루프 호출 심볼·줄 | 결정 연결 (a: 현재 판정 / b: 다음 세대 메타 상태 또는 루프 전이) | 파라미터·메타 상태 행동 변화 |
|---|---|---|---|---|---|
| M1 | | | | | |
| 채택 조건 | | | | | |
| 반증 조건 | | | | | |
| 난이도 상승 조건 | | | | | |
| 재실행 조건 | | | | | |

- **빈 칸·누락·더미·미호출·무영향·행동 불변 시 즉시 무효(`SSOT-NVFP4`의 `nvfp4_quantize` 양자화 및 감쇠 잔차 $\gamma$-수축·이산 점격자 최근접 사영 sub-claim 필수 포함).**
- **줄 번호는 완성된 `main.py`를 파이썬 `ast`(`def`/`class` 선언줄 `node.lineno`) 및 1-기반 줄 덤프(`enumerate(lines, start=1)`)로 실측해 ±1줄 이내(목표 0줄 오차)로 기입하라(2줄 이상 오차·주석 숫자 인용 시 무효).**
- **§2에서 "부수 요소"로 분류한 메커니즘은 이 표에 넣지 마라(기재 시 무효).**
- **메커니즘 이름과 실제 수학 동작이 일치해야 한다:** "확산(diffusion)"은 noise → data 반복 역전이 스텝이어야 하며(단순 변이 무효), "`NVFP4(E2M1)`"은 실제 `nvfp4_quantize` 비균일 격자 RNE 투영이어야 하며(균일 반올림 무효), "N개 검증기 순회"는 실제 N개 순회 루프여야 한다(단일 조건문 무효).
- **의미적 중복 금지 및 동치류 최소비용 교체 (`SSOT-Dedup`):** 구문만 바꿔 다른 이름으로 동시 중복 등록하면 무효다. 대칭 충돌 방지를 위해 **비대칭 직사각(`H≠W`) 격자·`1×L` 1D 격자·다중 소수값**을 모두 포함한 고정 프로브 집합 $\mathcal{X}_{\text{probe}}$(2~3개 프로브 $X_i$ 및 이항 매크로 `op(X, X)` 축퇴 방지용 비축퇴 순서쌍 `(X_i, X_j)`) 위에서의 출력 시그니처(`Semantic Signature`) 유일성으로 탐색·매크로 풀을 중복 제거하되, `SSOT-HV` 복잡도와 동형인 사전순 프로브 비용 튜플 `(probe_ops_count, c_size, syntax_sha256)`이 엄격히 더 작은 후보 발견 시 탐색 풀 대표를 교체(`Equivalence-Class Minimum-Cost Replacement`)하라(단, 파레토 아카이브 $\mathcal{P}_{g,t}$ 내 교체는 `SSOT-HV`의 $\Delta\text{HV}_g \ge 0$ 약우월 교체 조건을 따름).

### (b) 비-오라클(Anti-Oracle) 3종 직교 미니 태스크 & 은닉 OOD 분리

외부 Tier B가 아닌 배관·전이 검증용으로, `Grid` 위에서 작동하는 **인지적으로 직교하는 3종 공개 미니 태스크군(T1: 대수·산술 상태 전이, T2: 2D 공간·구조 불변량 변환, T3: 다단계 기호 규칙 환원 — 4단계 `d=0..3` 난이도 사다리 포함)**을 Phase 0 규격에 맞춰 `main.py`에 구현한다(마스터 외부 심판기는 은닉 시드 OOD 및 미공개 상위 합성 과업 `T4_hidden`을 추가 채점).
- **오라클 DSL 및 복합 분기 금지 (`SSOT-B0`):** 기본 DSL은 Phase 0에서 확정된 범용 원자 연산 기저 $\mathcal{B}_0$(8~10개 정본 `b0_<name>` 함수)만 허용한다:
  - **4대 `ast` 복잡도 상한 및 무데코레이터 원칙:** 각 함수 `fn`은 데코레이터 없는(`len(fn.decorator_list) == 0`) 최상위 유일 `def`로서 총 줄 수 `fn.end_lineno - fn.lineno + 1 <= 15`, 문장 수 `sum(1 for n in ast.walk(fn) if isinstance(n, ast.stmt)) <= 12`(`FunctionDef` 포함), 분기·단락제어 수 `sum(1 for n in ast.walk(fn) if isinstance(n, (ast.If, ast.IfExp, ast.Match, ast.BoolOp, ast.Try))) + sum(len(n.ifs) for n in ast.walk(fn) if isinstance(n, ast.comprehension)) <= 2`(경계·0 나눗셈 안전용; 포화 클램핑은 `max`/`min` 사용 권장), 전체 노드 수 `sum(1 for _ in ast.walk(fn)) <= 180` 이내여야 한다.
  - **직사각 닫힘 및 독립 리프 전함수:** `H>=1, W>=1` 임의 입력(이항 연산의 `H1×W1 ≠ H2×W2` 크기 불일치 조합 포함)에서 예외 없이 비공백 직사각 `Grid`(Phase 3 `Grid` 순수 `int` 셀 규격 준수 — 비교 연산도 `0`/`1` 순수 `int` 반환 필수, `H>=1, W>=1`)를 반환하고 외부 사용자 정의 헬퍼 및 타 `b0_*`를 일체 내부 호출하지 않고 순수 내장함수(`tuple`, `list`, `len`, `range`, `enumerate`, `min`, `max`, `abs`, `sum`, `int`, `zip`, `reversed`) 및 폴드·누적용 지역 `list.append` 메서드만 사용하는 독립 리프 기초 전함수(전치·반전·이동·슬라이싱·원소별 산술/모듈러/비교·축약·폴드 등)여야 하며, 룩업 테이블(`ast.Dict`·`ast.Set`·`ast.DictComp`·`ast.SetComp` 및 `dict`·`set` 생성자 호출)·태스크 식별자·특정 크기 분기·태스크 맞춤 매직 상수 포함 시 즉시 무효다(해결에는 최소 2개 이상 기본 요소 합성 및 커리큘럼 간 고차 추상화 승격 필수).
- **단일 요소 전수 검증:** 모든 단일 $\mathcal{B}_0$ 요소(이항은 `op(X, X)` 호출)의 전 단계 태스크별 정확도를 `k/n` 꼴로 실행 로그에 출력하라(어느 태스크·단계에서든 단일 요소 100% 정답 시 즉시 무효).
- **입력 실사용 및 완전 결정론 Baseline 3종 실측:** 입력 격자 실변환 코드를 인용하고, 정답 모양 유출 없는 Baseline 3종 — ① 무작위(입력과 동일 `H×W`, `Train` 출력 격자 전체 셀 값의 닫힌구간 `[min_val, max_val]` 균등 정수 고정 시드 난수 격자), ② 최빈값(입력과 동일 `H×W`를 `Train` 출력 최빈 셀 값[빈도 동률 시 최소 정수 `min` 선택]으로 채운 격자), ③ 항등(입력 그대로 반환) — 을 실제 계산해 `k/n`으로 출력하며 이를 유의미하게 능가해야 한다.
- **Train / OOD 엄격 격리:** 후보 생성·채택 중에는 `Train(n개)`만 참조하며, 채택 완료 후 더 큰 격자·길이·미등장 상수로 구성된 `OOD Test(m개)`(공개 OOD + 마스터 외부 심판기 은닉 OOD·`T4_hidden`) 점수를 분리 출력하라.

### (c) 루프 실행 및 사보타주 불가 Meta-Ablation

- **세대 전이 및 구조적 승격:** 총 4세대 이상 실행(`gen_idx = 0..G-1`, `G >= 4`; 세대 간 전이 3회 이상 및 `d=3` 도달·평가 포함, 예: 4~8세대) 및 최소 1회 이상 고차 추상화 연산자 발명·승격과 `current_stage` 상승 달성(채택 0 종료 시 무효).
- **동적 생성 및 유일성:** 모든 세대 후보는 메타 생성기로 동적 생성되어야 하며(하드코딩 무효), `SSOT-Dedup` 및 `SSOT-Soundness`(Phase ②·③ 프로브 규약)에 따라 평가 풀·아카이브 내 구문 해시 및 `Semantic Signature` 유일성을 유지해야 한다.
- **무사보타주 Meta-Ablation 대조:** 동일 `ops_budget` 하에서 `meta_update=True`와 `meta_update=False`를 비교하라(커리큘럼 루프 비교와 함께, 하위 단계 정체 착시 및 $L_{\max}=4$ 분모 차이 왜곡 배제를 위해 초기화된 `RSIEngine(seed, meta_update=False)`에 최종 단계 `d=3` 과업을 동등 `ops_budget`으로 직접 공급했을 때의 **과업별 `d=3` `Train`·`OOD` `k/n` 정확도 비교**도 함께 출력). **`SSOT-AST` `meta_update` 비사보타주 규칙을 어기거나 `gen_idx`·매크로 보유 수가 후보 생성·탐색 깊이·채점·전선 갱신·단계 상승·해법 바인딩 내부에서 직간접 열화 분기를 타면 즉시 무효**이며, 초기 `RSIEngine` 대조군 대비 누적 학습 엔진이 `T3`(`d=3`) 및 `T4_hidden` 은닉 OOD `k/n` 정확도에서 유의미하게 우월해야 한다.
- **실행 로그 무결성 및 `SSOT-HV` 일치:** 모든 정확도는 `k/n`으로 표기하고 `SSOT-HV` 산식을 한 줄로 인용해 `main.py`에 동일하게 구현하며, `main.py` 표준 출력과 Phase 4 외부 심판기 출력(Phase 0·3 SHA-256 일치, `SSOT-Forensic` 위반 `0건`, AST·선택적 `sys.setprofile` 예산·`nvfp4_quantize` 실호출·`unpruned_ops`·`predict` `B0_OPS` 변조 파생·은닉 OOD/Meta-Ablation 및 2회 결정론 결과 포함)을 가감 없이 수록하라(본문·표 수치와 실행 출력이 단 하나라도 불일치 시 무효).

### (d) 결정론적 재현성 및 4대 조건 전수 검증

- **시드·해시 완전 결정론:** 난수 시드를 고정하고, `PYTHONHASHSEED` 비결정성 차단을 위해 **내장 `hash()` 및 비정렬 `set` 순회·`set.pop()`을 금지(`b0_<name>` 함수 바깥에서의 무정렬 순회 없는 `in` 멤버십 전용 `set`[예: §5(f) 감사 집합·Tabu 멤버십 등, 또는 삽입 순서가 보존되는 `dict` 기반 집합]만 허용)하고 `hashlib.sha256` 및 정렬/`dict` 삽입 순서만 사용**하라. `SSOT-HV` 3축 외 wall-clock·`sys.getsizeof` 등 플랫폼 의존 지표를 금지하며, 세대별 판정 로그는 상대 경로 `./rsi_generations.jsonl`(`/tmp` 하드코딩 금지)에 기록하라.
- **미검증 분기 제로화:** 모듈 최상위 `verify_four_conditions()`(`log_path=None`으로 메인 로그 보호)에서 4대 조건(채택·반증[`ckpt_stack` 실질 메타 복원, $\mathcal{P}_{g,t}$ 보존 및 Tabu 등록 포함]·난이도 상승·재실행[`SSOT-Soundness` 선예약 $\ge 25\%$ `unpruned_ops` 집행 포함]) 전 분기를 결정론적 시나리오로 실제 트리거하고 동작 로그 및 정본 4개 키(`{"adoption", "falsification", "difficulty_escalation", "retry"}`, 전 키 순수 `bool` `True`[`v is True`]) 통과 딕셔너리를 출력·반환하라.

### (e) Tier B 연동

`abc.ABC`를 상속하되 `@abstractmethod` 봉쇄 대신 기본 메서드가 `NotImplementedError`를 발생시켜 **기반 클래스 자체 및 15개 구상 서브클래스 전부의 무인자 인스턴스화(`cls()`)가 가능한** `TierBAdapter`(`load(self) -> object`, `score(self, predictions: object = None) -> float`, `budget(self) -> dict[str, object]`, `protocol(self) -> dict[str, object]`) 및 `SSOT-TierB` 15개 정본 키와 1:1 매핑되는 `TIER_B_REGISTRY`(타입은 Phase 3 심볼 계약 참조)를 구현하라:
- **`budget()` 정본 6키 및 `SSOT-HW`·`SSOT-Mem` 불변 범위:** 필수 키 `{"vram_bytes", "dram_bytes", "nvme_bytes", "flops", "power_w", "energy_j"}`(15종 어댑터별 6튜플 상호 고유성 및 비-`bool` 유한 수치 필수), `4,096 B` 페이지 정렬 정수(`% 4096 == 0`) `0 <= vram_bytes < 384*10**9`·`0 <= dram_bytes < 1000*10**9`·`0 < vram_bytes + dram_bytes < 1384*10**9`, 정수 `0 <= nvme_bytes <= int(10.0*10**12)`, `flops > 0`, `160 <= power_w <= 1550`(연산 서브시스템 $P_{\text{compute}}$), `energy_j > 0`(1회 평가 연산 서브시스템 소비 에너지 $E_{\text{compute}} = \text{power\_w} \cdot T_{\text{eval}}$ [`J`]), 그리고 최소 런치 지연 $1\;\mu\text{s}$·`14.044 PFLOPS` 광속 하한 `energy_j / power_w >= 1e-6 + flops / (14.044 * 10**15)`을 모두 충족하여 §4 표와 1:1 일치시킬 것.
- **`protocol()` 정본 5키 및 실행 경계:** 필수 키 `{"transducer", "cadence_gens", "isa_mode", "metric", "pareto_axes"}`(비-`bool` `int` `cadence_gens >= 1`, `"transducer"`·`"isa_mode"`·`"metric"`은 선행 슬래시 경로 없는 비공백 순수 ASCII `str`, `"pareto_axes"`는 비공백 순수 ASCII `str` 원소 1개 이상의 `tuple`/`list`)를 반환하고, 외부 하네스가 필요한 `load()`와 `score()`만 `NotImplementedError`를 발생시킬 것.

### (f) 네트워크 및 외부 프로세스 커널급 강제 차단

런타임 네트워크·외부 명령 실행을 원천 차단하는 아래 2중 비가역 가드를 `main.py` 최상단에 필수로 구현하라:
- **소켓 메서드 패치:** 표준 라이브러리 상속 호환성을 위해 `socket.socket` 클래스 자체를 함수로 덮어쓰지 말고(`socket.socket.__new__` 유지), `socket.socket.connect`, `socket.socket.connect_ex`, `socket.create_connection` 3종을 `RuntimeError` 발생 함수로 패치하라.
- **`sys.addaudithook` 정본 무상태 가드 고정:** 모듈 최상단 단일 `sys.addaudithook` 호출로 **2번째 인자(매개변수명 무관, 예: `_args`·`_`; 함수 본문 및 `*vararg` 내 미참조)를 일절 참조하지 않고 `global`·`nonlocal`·속성·컨테이너 상태 변이가 전무한 무상태 순수 가드 함수**를 등록하여, 정본 이벤트 집합 `{'socket.connect', 'socket.bind', 'socket.sendto', 'socket.sendmsg', 'socket.getaddrinfo', 'socket.gethostbyname', 'socket.gethostbyaddr', 'socket.getnameinfo', 'os.system', 'os.popen', 'os.spawn', 'os.posix_spawn', 'os.exec', 'os.fork', 'os.forkpty', 'os.startfile', '_winapi.CreateProcess'}` 및 정본 접두어 `('urllib.', 'http.', 'ftplib.', 'smtplib.', 'poplib.', 'imaplib.', 'xmlrpc.', 'subprocess.', 'ctypes.')` 매칭 시 즉시 `RuntimeError`를 발생시켜라(**마스터 외부 심판기의 `sys.setprofile`·`compile`[`ast.parse`]·`open` 호환성 파괴, 인프로세스 부채널 감청 및 포렌식 API 정규식 오탐 방지를 위해 위 정본 집합·접두어 외 임의 이벤트 문자열 추가나 2번째 인자/상태 접근 절대 금지**).
